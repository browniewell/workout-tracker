# Workout Consistency Tracker

> 🚧 **WORK IN PROGRESS** — actively being built. Expect missing features and rough edges.

A personal tracker focused on **consistency, not intensity**: it answers "am I showing up?", not "am I getting stronger?"

The v1 goal is simple: **don't miss two days in a row.** Planned rest days and sick days never count as misses.

## Planning

Work is planned as stories in GitHub Issues and tracked on the project board. Each PR links to the story it delivers.
